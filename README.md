# personal_skills

收录有价值的 skills，保存完整文件的独立副本。各目录的 `SKILL.md` 是使用入口。

| Skill | 用途 |
| --- | --- |
| [compact-code-notes](compact-code-notes/SKILL.md) | 按 VE CUDA Graph 笔记的紧凑风格撰写、续写或精简中文源码学习笔记。 |
| [ponytail](ponytail/SKILL.md) | 以最小完整改动解决问题的开发工作流。 |
| [anthropic-skill-creator](anthropic-skill-creator/SKILL.md) | 创建、改进并通过样例验证 skills。 |

`compact-code-notes` 为本地创建；`ponytail` 按现有本地版本收录，许可证标识见其 `SKILL.md`。

`anthropic-skill-creator` 来自 [Anthropic 官方仓库](https://github.com/anthropics/skills/tree/dbd4588f9e1033efb41dad4bef2f7947c8993d44/skills/skill-creator)，固定版本为 `dbd4588f9e1033efb41dad4bef2f7947c8993d44`。本地调整了 skill 名称并增加 Codex 界面元数据，保留上游正文、配套资源和 [Apache 2.0 许可证](anthropic-skill-creator/LICENSE.txt)。
